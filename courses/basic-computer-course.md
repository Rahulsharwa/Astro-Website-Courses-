# Basic Computer Course

## Start Using Computers with Confidence

This beginner-friendly course teaches the essential computer skills needed for study, work, communication, and daily digital life.

## What You Will Learn

- Parts of a computer and basic terminology
- Keyboard, mouse, desktop, and Windows basics
- Creating, saving, copying, and organizing files
- Internet browsing, search, email, and online forms
- Basic typing and document preparation
- Printing, scanning, and safe use of USB devices
- Cybersecurity, passwords, and digital awareness

## Course Highlights

- No prior computer experience required
- Step-by-step practical instruction
- Individual practice time and guided exercises
- Certificate on successful completion

## Recommended For
